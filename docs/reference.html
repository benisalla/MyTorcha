mytorcha.optim

Every optimizer has step(), zero_grad(), lr (read/write), params, per-parameter state, and state_dict() / load_state_dict(). Schedulers have step(), which returns the new lr.

NameDescription
optim.SGD
(params, lr=0.01, momentum=0.0, nesterov=False, weight_decay=0.0, dampening=0.0)
w -= lr·g, optionally with momentum (a running sum of past gradients) and Nesterov look-ahead. weight_decay adds wd·w to the gradient (L2 penalty).
optim.Adagrad
(params, lr=0.01, eps=1e-10, weight_decay=0.0)
Divide by sqrt(sum of all past g²): rarely-updated weights get bigger steps.
optim.RMSprop
(params, lr=0.01, alpha=0.99, eps=1e-08, momentum=0.0, centered=False, weight_decay=0.0)
Adagrad with a *moving average* of g², so the step size does not decay to 0.
optim.Adadelta
(params, lr=1.0, rho=0.9, eps=1e-06, weight_decay=0.0)
RMSprop whose step size is itself a running RMS of past updates (no lr tuning).
optim.Adam
(params, lr=0.001, betas=(0.9, 0.999), eps=1e-08, weight_decay=0.0, amsgrad=False)
Momentum (m, 1st moment) + RMSprop (v, 2nd moment) + bias correction.
optim.AdamW
(params, lr=0.001, betas=(0.9, 0.999), eps=1e-08, weight_decay=0.01, amsgrad=False)
Adam with *decoupled* weight decay: shrink weights directly instead of adding wd·w to the gradient (which Adam's normalisation would rescale).
optim.Adamax
(params, lr=0.002, betas=(0.9, 0.999), eps=1e-08, weight_decay=0.0)
Adam with the infinity norm: v = max(β2·v, |g|).
optim.Lion
(params, lr=0.0001, betas=(0.9, 0.99), weight_decay=0.0)
Lion (Chen et al., 2023): step by the SIGN of an interpolated momentum. Every weight moves by exactly ±lr, so use a ~10x smaller lr than Adam.
optim.clip_grad_norm_
(params, max_norm)
Rescale all gradients together so their global L2 norm is <= max_norm. Essential for RNNs, whose gradients can explode. Returns the norm before clipping.
optim.StepLR
(optimizer, step_size, gamma=0.1)
Multiply lr by gamma every step_size epochs.
optim.ExponentialLR
(optimizer, gamma)
Multiply lr by gamma every epoch.
optim.CosineAnnealingLR
(optimizer, T_max, eta_min=0.0)
Smoothly decay from base_lr to eta_min over T_max epochs along a half cosine.
optim.LambdaLR
(optimizer, fn)
lr = base_lr · fn(epoch). E.g. linear warm-up: LambdaLR(opt, lambda e: min(1, (e + 1) / 10)).
